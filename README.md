# Minibatch-SGD-Inventory-Supplement
本项目包含一项基于合成数据的库存优化补充实验，考察 minibatch SGD 在多产品、多资源约束系统中的批量降噪、更新频率与需求变化响应之间的权衡。

> **实验边界：** 本项目是对相关论文方法的合成实验扩展，不是对原论文数值结果或理论保证的复现。所有需求、成本与资源参数均为本实验自行设定；没有使用企业数据。

## 文件

- [`批量SGD_合成库存实验.ipynb`](./批量SGD_合成库存实验.ipynb)：实验代码、参数说明、结果汇总及图表。

## 实验设计

- **库存系统：** 3 种产品、2 项共享资源约束、连续库存目标；目标库存通过投影满足共同可行域。
- **需求：** 各产品需求独立服从 Poisson 分布。稳态场景固定均值；非平稳场景在第 600 期改变均值。
- **规模与重复：** 每次运行 1,200 期，12 个配对随机种子；同一重复内各算法面对相同需求路径。
- **共同设置：** 初始库存为 `(7, 8, 7)`，学习率 `η = 0.03`，成本函数和资源约束在各组间保持一致。
- **固定批量组：** 标准 SGD `B=1`，以及 `B=10、50、100`。
- **自适应扩展：** 常态批量 `B=50`；EWMA 变化检测（`α=0.18`，阈值 `2.00`）触发后切换到 `B=1` 持续 60 期，再恢复 `B=50`。检测器读取完整合成需求向量，这是额外假设，不属于原论文算法。

当新目标低于当前库存时，实验通过一个投影子问题计算满足资源约束且不低于当前库存的最近可执行库存。Regret 根据已知合成需求分布的离线最优成本计算；在线策略不会使用这些真值。平均成本则基于模拟路径上的实际成本。

## 主要结果

以下为 12 个配对种子的实验结果。运行时间受机器环境影响，未列作跨机器结论。

| 场景 | 结果 |
| --- | --- |
| 稳态：`B=1` 到 `B=100` | 解析梯度批方差由 `27.13` 降至 `0.32`；累计 Regret 均值由 `390.1` 增至 `2,120.4`；目标更新约由 `1,192` 次降至 `12` 次。 |
| 需求突变：固定大批量 | `B=50` 与 `B=100` 在突变后的 600 期内均未达到预设恢复标准；`B=10` 平均约需 `349` 期恢复。 |
| 需求突变：自适应 `50→1` | 平均检测延迟 `6.7` 期，平均恢复时间 `36.8` 期；变化后前 100 期平均成本 `27.05`，低于固定 `B=50` 的 `40.35`。 |
| 标准 SGD 基线 | `B=1` 的动态累计 Regret 均值为 `705.0`，平均恢复时间 `32.8` 期，在本组动态设置中优于自适应方案。 |
